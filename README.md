# Система биометрического контроля и мониторинга состояния операторов

Программно-аппаратный комплекс для автоматизированной регистрации, биометрической верификации, голосового управления и мониторинга функционального состояния операторов в реальном времени. Система объединяет алгоритмы компьютерного зрения и анализ физиологических показателей (пульсометрия / ЭМГ) для своевременного выявления признаков утомления, потери внимания и критических состояний во время рабочей смены.

---

## Основные возможности

* **Биометрическая регистрация и калибровка:**
  * Регистрация профилей операторов с проверкой возрастных ограничений ($\ge 18$ лет) и автоматическим ведением локальной базы данных.
  * Автоматический захват серии снимков лица с контролем геометрии взгляда, открытости глаз и резкости изображения (дисперсия оператора Лапласа).
  * Расчет индивидуальных физиологических порогов пульса (`норма`, `внимание`, `критично`) на основе 30-секундного калибровочного замера.
* **Двухфакторная авторизация и голосовое управление:**
  * Верификация оператора по геометрии лица (порог совпадения $\ge 80\%$) и предсменный контроль частоты сердечных сокращений (ЧСС).
  * Непрерывное фоновое распознавание голосовых команд и синтез речевых уведомлений без отвлечения оператора от основного процесса.
* **Мониторинг в реальном времени (Рабочий режим):**
  * **Видеоаналитика усталости:** отслеживание длительного закрытия глаз ($> 2\text{ с}$), критического наклона головы ($> 30^\circ$) и признаков зевания по 468 ключевым точкам лица.
  * **Физиологический контроль:** непрерывное считывание данных с микроконтроллера по последовательному порту и сопоставление с индивидуальными порогами оператора.
  * **Контроль времени смены:** автоматический учет времени в пути и обратный отсчет допустимой продолжительности смены (9 часов) с поддержкой пауз.
  * **Интегральная оценка статуса:** динамический расчет состояния (`НОРМА`, `ВНИМАНИЕ`, `КРИТИЧНО`) со звуковой и голосовой сигнализацией.
* **Диспетчерский пульт (Удаленный мониторинг):**
  * Наблюдение за подключенными операторами в реальном времени с задержкой передачи данных $\le 2\text{ с}$.
  * Автоматический контроль целостности канала связи, отображение ленты событий и возможность удаленного сброса сигнала тревоги.

## Архитектура системы

Проект разделен на четыре функциональных модуля, взаимодействующих через единое хранилище данных и сетевой интерфейс:

1. **Модуль регистрации (`Форма №1`):** сбор анкетных данных, создание эталонного фотопрофиля и базовая калибровка датчиков.
2. **Модуль авторизации (`Форма №2`):** предсменный допуск на основе сверки биометрии и текущего пульса, управляемый голосом.
3. **Модуль мониторинга оператора (`Форма №3`):** основной рабочий экран оператора с активной видеоаналитикой, опросом датчиков, таймерами смены и локальным сервером телеметрии.
4. **Диспетчерский клиент (`Окно выбора` и `Форма №6`):** приложение диспетчера для фильтрации операторов, просмотра показателей в реальном времени и обработки экстренных уведомлений (`ALERT`).

* **Графический интерфейс (GUI):** `Tkinter` / `PyQt5`, `Pillow`

* **Видеозахват:** стандартная USB веб-камера и микрофон.

```bash
git clone https://github.com/Gidret/professionali.git
cd neuro-operator-monitoring
python -m venv venv

# Активация окружения (Windows)
venv\Scripts\activate

```

### 2. Установка зависимостей
```bash
pip install opencv-python mediapipe pyserial pillow pyttsx3 SpeechRecognition pyaudio numpy
```

### 3. Подготовка аппаратной части
1. Подключите датчик пульса / ЭМГ к аналоговому входу `A0` платы Arduino Uno (питание `5V` и `GND`).
2. Загрузите управляющую прошивку в микроконтроллер через Arduino IDE (скорость порта `9600 бод`, формат вывода: `BPM: <значение>`).
3. Подключите плату к ПК по USB — система автоматически определит активный COM-порт при запуске.

### 4. Запуск приложений
```bash
# Запуск клиентского приложения оператора
python main_operator.py

# Запуск диспетчерского пульта мониторинга
python dispatcher_app.py
```

## Математические модели и алгоритмы

### 1. Оценка качества фотоснимка и положения головы
* **Резкость кадра:** вычисляется как дисперсия оператора Лапласа по области лица в градациях серого:
  $$\text{Sharpness} = \text{Var}(\nabla^2 I_{\text{gray}})$$
* **Степень открытости глаз (EAR — Eye Aspect Ratio):** определяется отношением вертикального расстояния между веками к горизонтальной ширине глаза по ключевым точкам сетки лица. Глаз считается открытым при $\text{EAR} > 0.19$.
* **Выбор эталонного кадра:** из серии в 5 стабильных снимков (сделанных с интервалом $0.5\text{ с}$) выбирается кадр, максимизирующий целевую функцию:
  $$S = \text{Sharpness} - 5 \cdot |\theta_{\text{roll}}|$$
  где $\theta_{\text{roll}}$ — угол наклона головы в градусах.

### 2. Расчет индивидуальных порогов ЧСС
На основе массива значений ЧСС, собранных за 30 секунд в состоянии покоя, вычисляются три показателя:
* **Индивидуальная норма:**
  $$\text{pulse\_normal} = \text{round}\left(\frac{1}{N}\sum_{i=1}^{N} \text{BPM}_i\right)$$
* **Порог внимания (предупреждение):**
  $$\text{pulse\_threshold\_warning} = \lceil \text{pulse\_normal} \times 1.15 \rceil$$
* **Критический порог:**
  $$\text{pulse\_threshold\_critical} = \lceil \text{pulse\_normal} \times 1.30 \rceil$$
* **Допустимый коридор при предсменной авторизации:**
  $$0.8 \times \text{pulse\_normal} \le \text{current\_pulse} \le \text{pulse\_threshold\_warning}$$

## Структура хранения данных

Все данные сохраняются локально в кодировке `UTF-8` с разделителем `,`.

```text
├── operators/                   # Каталог эталонных биометрических снимков
│   └── ID_00001.jpg             # Фотографии операторов (формат ID_XXXXX.jpg)
├── operators_db.csv             # Основная база данных операторов и их текущих метрик
├── events_log.csv               # Журнал событий, тревог и срабатываний аналитики
└── auth_attempts.log            # Лог неуспешных попыток авторизации
```

### Поля базы данных `operators_db.csv`
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | `INTEGER` | Уникальный идентификатор оператора (автоинкремент с 1) |
| `last_name`, `first_name`, `middle_name` | `STRING` | Фамилия, Имя, Отчество оператора |
| `age` | `INTEGER` | Возраст полных лет ($\ge 18$) |
| `date`, `time` | `STRING` | Дата (`ГГГГ-ММ-ДД`) и время (`ЧЧ:ММ:СС`) регистрации |
| `software_start_time` | `STRING` | Время начала текущей рабочей смены |
| `drive_duration` | `INTEGER` | Фактическое время в пути (в секундах) |
| `pulse_threshold_warning` | `INTEGER` | Индивидуальный порог внимания ЧСС (уд/мин) |
| `pulse_threshold_critical` | `INTEGER` | Индивидуальный критический порог ЧСС (уд/мин) |
| `pulse_normal` | `INTEGER` | Базовая норма ЧСС в покое (уд/мин) |
| `current_pulse` | `INTEGER` | Текущее значение ЧСС в реальном времени |
| `operator_status` | `STRING` | Текущий интегральный статус (`НОРМА` / `ВНИМАНИЕ` / `КРИТИЧНО`) |
| `verification_result` | `STRING` | Статус последней биометрической верификации |
| `last_voice_command` | `STRING` | Последняя выполненная голосовая команда |

### Структура журнала событий `events_log.csv`
Записывает все изменения состояния в формате:
`timestamp, id, event_type, event_text, pulse_value, operator_status, source`
* **Типы событий (`event_type`):** `WARNING`, `CRITICAL`, `STATUS_CHANGE`, `VOICE_COMMAND`, `TIMER`.
* **Источники (`source`):** `camera` (видеоаналитика), `sensor` (пульсометр), `voice` (голосовое управление), `timer` (таймер смены).

## Справочник голосовых команд

Микрофон работает в фоновом потоке на протяжении всего сеанса работы с системой.

### Режим авторизации
* **«Авторизация» / «Войти» / «Начать работу»** — запуск сканирования лица и предсменного замера пульса.
* **«Да» / «Нет»** — подтверждение или отмена перехода в рабочий режим после успешной верификации.
* **«Помощь»** — голосовое перечисление доступных команд.

### Рабочий режим (Мониторинг в пути)
* **«Статус»** — озвучивание текущего интегрального статуса, пульса и остатка времени смены.
* **«Пульс»** — озвучивание текущей частоты сердечных сокращений.
* **«Сколько осталось»** — озвучивание оставшегося допустимого времени в пути.
* **«Пауза» / «Продолжить»** — приостановка и возобновление таймера учета рабочего времени на время стоянки.
* **«Повтори последнее сообщение»** — повтор последнего речевого уведомления системы.
* **«Помощь»** — справка по голосовым командам рабочего режима.
